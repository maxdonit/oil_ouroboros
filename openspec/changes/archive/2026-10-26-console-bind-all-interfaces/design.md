## Context

Мотивация — proposal.md (Why). Порты консоли (`38620`) и UI Ouroboros (`38630`, профиль owner) публикуются на один
адрес `OILO_BIND`; в `docker-compose.yml` его запасное значение без `.env` — `127.0.0.1`, в шаблоне `.env.example` —
тоже `127.0.0.1`. На сервере с несколькими интерфейсами (например, физическая карта в сети роутера и мост виртуальных
машин) консоль с адресом одного интерфейса не принимает запросы на другом, а проброс порта роутера ведёт на адрес
физической карты.

## Goals / Non-Goals

**Goals:** после `init_env.py` и `docker compose up -d` консоль открывается по любому адресу хоста — с этой машины,
из сети и через проброс порта.

**Non-Goals:** раздельные адреса для консоли и UI Ouroboros, вход в консоль, HTTPS (proposal.md, Non-goals).

## Decisions

1. **Значение в шаблоне `.env.example`, а не в `docker-compose.yml`.**
   - Вариант А — `OILO_BIND=0.0.0.0` в шаблоне (выбран): новая установка получает его через `init_env.py`, а запуск
     без `.env` (тесты, `docker compose config` в CI) остаётся на безопасном `127.0.0.1`; существующие `.env` не
     меняются.
   - Вариант Б — сменить и запасное значение в compose: два места правды не нужны для цели, а сценарий «Порты по
     умолчанию» и тесты карты развёртывания пришлось бы переписать без пользы.
   - Вариант В — отдельный `CONSOLE_BIND` для консоли: UI Ouroboros остался бы только локальным, но это новый параметр
     и правка compose; владелец выбрал один общий адрес.
2. **Параметров не добавляется**: меняется только значение `OILO_BIND` в шаблоне. Версия агента не меняется — `.env`
   в отпечаток не входит.

## Risks / Trade-offs

- [Консоль без пароля видна всем в сети хоста, включая запуск eval] → так решил владелец: вход должен быть простым;
  потолок денег — лимит шлюза `GATEWAY_BUDGET_USD`; вернуть только эту машину — `OILO_BIND=127.0.0.1`.
- [UI Ouroboros с паролем по умолчанию `ouroboros` тоже виден в сети хоста] → в `.env.example`, `operations.md` и
  `owner.md` — напоминание сменить `OUROBOROS_PASSWORD` и не пробрасывать порт 38630 наружу.

## Migration Plan

Новые установки — сразу. Существующая установка: `OILO_BIND=0.0.0.0` в `.env`, затем
`docker compose up -d console ouroboros-ui`. Откат — `OILO_BIND=127.0.0.1` и та же команда.
