# Proposal

## Why

После установки в консоль трудно попасть:
- `scripts/init_env.py` генерирует случайные пароли (`UI_USERS`), их надо искать в `.env`;
- без логинов консоль отвечает 503;
- открыть её без пароля можно только явным `UI_OPEN=true`, и то лишь при публикации на `127.0.0.1`.

Владелец проекта решил, что войти после запуска должно быть легко, а защита входа здесь только мешает
воспользоваться проектом.

## What Changes

- **BREAKING** Паролей и ролей у консоли больше нет. Она открывается сразу, сервер не проверяет ни логинов, ни прав:
  все эндпоинты открыты. Параметры `UI_USERS` и `UI_OPEN` удаляются. Консоль больше не читает `OILO_BIND` — он
  остаётся только адресом публикации портов.
- Консоль открывается в **простом режиме**: вкладки «Чат» и «Прогноз». Кнопка в шапке «Режим администратора»
  показывает все вкладки, кнопка «Простой режим» возвращает обратно. Выбор запоминается в браузере. Ссылка на вкладку
  администратора, например `#/turns/<id>`, сама включает этот режим.
- `GET /api/health` всегда отдаёт подробности: состояние tools, шлюза и Ouroboros.
- Разговоры не привязаны к логину: id нового разговора — `c-<10 hex>`, продолжить или прочитать разговор может любой,
  кто знает его id. Прежние id работают.
- `/api/me` удаляется: режим выбирает интерфейс, а не сервер.
- `scripts/init_env.py` больше не создаёт `UI_USERS`. Из `.env.example`, compose (`x-no-secrets` и окружение
  `console`) и документов уходят логины, 503, «временная консоль без входа» и `UI_OPEN`. Имена попадают в `LEGACY`
  теста согласованности.
- На стенде из `.env` удаляется `UI_USERS`. Консоль на `192.168.41.1:38620` становится открытой без пароля всем в
  этой сети.

Не входит (Non-goals):
- Пароль собственного UI Ouroboros (профиль `owner`, `OUROBOROS_PASSWORD`). Это вход самого агента, его задаёт
  Ouroboros, отдельный вопрос.
- Токены между сервисами (`TOOLS_API_TOKEN`, `GATEWAY_TOKEN_*`, `MCP_TOKEN`). Их генерирует `init_env.py`, вход
  пользователя они не усложняют.
- Адрес публикации по умолчанию `127.0.0.1` (`OILO_BIND`). Открыть консоль в сеть — одна строка `.env`, как сейчас.

## Capabilities

### New Capabilities
(нет)

### Modified Capabilities
- `console-ui`: вместо входа и ролей — открытая консоль с простым режимом и режимом администратора; здоровье с
  подробностями всем; секреты «Параметров» без `UI_USERS`; вкладки «Архитектура» и «Источники» — по режиму.
- `agent-turn`: разговор не принадлежит логину — id `c-<10 hex>`, доступ по id.
- `agent-eval`: вкладка «Качество» — в режиме администратора, API без ролей.
- `data-sources`: вкладка «Источники» — в режиме администратора, прокси без ролей.
- `demo-replay`: вкладка «Демо» — в режиме администратора, API без ролей.
- `price-forecast`: API вкладки «Прогноз» открыт без входа, вкладка — в обоих режимах.
- `deployment`: `UI_USERS` нет в `x-no-secrets`, в окружении консоли и в `.env` от `init_env.py`.
- `agent-bootstrap`: среди обнуляемых чужих секретов нет `UI_USERS`.

## Impact

- Код: `src/oil_ouroboros/console/app.py` (вход, роли, `/api/me`, здоровье, разговоры), `src/oil_ouroboros/config.py`
  (`ui_users`, `ui_open`, `oilo_bind`), `scripts/init_env.py`.
- UI: `ui/main.js`, `ui/util.js`, `ui/api.js`, `ui/index.html` (кнопка режима вместо «кто вошёл»).
- Конфигурация: `docker-compose.yml`, `.env.example`.
- Тесты: `tests/test_console.py`, `tests/conftest.py`, `tests/test_consistency.py` (`LEGACY`).
- Документы: README, `docs/guide/parameters.md`, `docs/guide/operations.md`, `.claude/skills/sdd/SKILL.md`
  (проверка UI — в обычной консоли).
- Версия агента не меняется: каталог, регламент и память агента не затронуты.
