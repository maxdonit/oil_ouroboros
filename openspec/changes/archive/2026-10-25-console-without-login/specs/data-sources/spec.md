# Spec Delta

## MODIFIED Requirements

### Requirement: Доступ через консоль
Консоль SHALL проксировать `GET /api/sources` и `GET /api/sources/domain` в сервис инструментов (`TOOLS_URL`) с
токеном `TOOLS_API_TOKEN` без входа; вкладка «Источники» (`sources`) есть в режиме администратора (режимы — спека
`console-ui`).

#### Scenario: Без вкладки «Источники»
- **WHEN** консоль в простом режиме
- **THEN** вкладки «Источники» нет, а `GET /api/sources` без входа отвечает как обычно

#### Scenario: Вкладка «Источники» открыта
- **WHEN** в режиме администратора открыта вкладка «Источники»
- **THEN** консоль отдаёт ответ сервиса инструментов как есть
