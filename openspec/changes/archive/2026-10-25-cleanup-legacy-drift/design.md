# Design

## Context

Мотивация и состав — proposal.md. Находки шести аудитов собраны в один change, потому что почти все они — уборка без
изменения поведения: удаление недостижимого кода, тексты и одна точка правды для дублей. Изменения поведения здесь
только мелкие и вытекают из уже принятых доработок (роль `user` без «Ходов», GigaChat по умолчанию).

## Goals / Non-Goals

**Goals:** ни одного мёртвого пути и ни одного текста, расходящегося с кодом, в затронутых местах; дубли, которые уже
однажды разошлись (список инструментов, префиксы меток), — из одного места; тест ловит устаревшее число инструментов.

**Non-Goals:** исправление найденных ошибок поведения и крупные перестройки — строками плана (proposal.md, Non-goals).

## Decisions

1. **Что считается мёртвым.** Удаляется только то, на что нет ни одной ссылки по `git grep` во всём репозитории
   (код, UI, тесты, конфигурация) и что не обязан принимать интерфейс: заглушки и протоколы (`llm/fake.py`,
   `rag/vectors.py` `Embedder`/`NoReranker`, параметры провайдеров веба) остаются. Совместимость `ui/md.js` со старой
   меткой «Расчётный модуль …» остаётся: на стенде 7 записанных ходов из 535 её содержат.
2. **Одна точка правды без новых зависимостей между сервисами.** Список расчётных инструментов —
   `evals/checks.CALC_TOOLS`, консоль берёт его оттуда: `evals.retrieval` работает в tools, и импорт
   `console.turns` из `checks` потянул бы код консоли в tools. Маркеры подвала и префиксы меток — в `evidence/text.py`
   (чистый модуль, его уже импортирует консоль). `smoke.MCP` не импортирует `mcp.server` (тяжёлые зависимости в
   образе консоли) — равенство проверяет тест.
3. **Цена GigaChat.** Префикс `GigaChat` — тот же, по которому шлюз маршрутизирует в gpt2giga (`gateway/app.py`
   `GIGACHAT_PREFIX`); `pricing.cost` возвращает 0 до чтения каталога. Альтернатива — `fetch=False` в `llm/core.py` —
   выключила бы и обновление каталога для профиля openrouter.
4. **Тест числа инструментов.** Регулярка «N инструмент… MCP» / «N MCP» по документам, compose, схеме и docstring'ам —
   N должно равняться `len(TOOLS)`; так «8 инструментов» не вернётся при следующем инструменте.

## Risks / Trade-offs

- [Удаление параметров ломает вызов, которого не видно grep'ом (по строке, из шаблона)] → полный pytest, проверка
  ES-модулей и живой ход на стенде.
- [Тексты разойдутся снова при следующей доработке] → тест числа инструментов и дельты спек; остальное — шаг `docs`
  в задачах каждого change.
