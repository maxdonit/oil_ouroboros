# Environment Profile

- **Установка.** Проект oil_ouroboros: контейнер `ouroboros` (официальный образ razzant/ouroboros v7.7.0, Linux).
  Режим `advanced` выбирает владелец в своём UI. В задачах консоли действуют её правила: только инструменты
  `mcp_oil__*`, себя не меняю.
- **Сеть.** Прямого выхода в интернет нет: внутренняя сеть `agent` (Telegram и навыки владельца — через прокси
  `egress`). LLM — через шлюз проекта (openai-compatible, жёсткий лимит денег). Веб — только через
  `mcp_oil__research` / `mcp_oil__search_web`: там фильтр жёлтой прессы и уровни доверия источников.
- **Пользователи.** Аналитики и тестировщики через консоль проекта. Каждый вопрос — задача API; последние реплики
  диалога консоль передаёт в тексте задачи.
- **Мои инструменты для работы (MCP-сервер `oil`, сервис tools на LangGraph):**
  - `mcp_oil__research` — база отчётов агентств (состав — `mcp_oil__list_reports`), оценка достаточности, веб по
    политике приоритета;
  - `mcp_oil__search_reports`, `mcp_oil__search_web` — точечный добор;
  - `mcp_oil__forecast_price`, `mcp_oil__supply_shock_scenario`, `mcp_oil__price_history` — расчётный модуль на рядах
    EIA;
  - `mcp_oil__price_quote` — текущая цена Brent, WTI, газа Henry Hub или TTF: котировка фьючерса на Мосбирже и
    спот EIA;
  - `mcp_oil__verify_answer` — проверка цифр черновика по источникам;
  - `mcp_oil__list_reports` — что есть в базе отчётов.
- **Данные.** Два последних выпуска каждой серии отчётов (что именно — `mcp_oil__list_reports`). Дневные цены Brent и
  WTI EIA (выкладываются раз в неделю); котировки фьючерсов ближайшего месяца на Мосбирже — Brent, WTI, газ Henry Hub и TTF (задержка 15 минут);
  Urals = Brent минус сценарный дисконт.
- **Встроенные инструменты** работы с кодом, файлами, shell, git и браузером в задачах консоли отключены.
