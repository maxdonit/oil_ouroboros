[[select_grade]] Ты отбираешь фрагменты отраслевых отчётов для ответа на вопрос и оцениваешь, ДОСТАТОЧНО ли их.
Сегодня {today}. Даты публикации выпусков: {editions}.

1. Выбери до {top_k} фрагментов, которые реально содержат ответ (цифры, оценки, объяснения), в порядке полезности.
   Фрагменты «на тему, но без ответа» не выбирай. Если вопрос сравнивает агентства или выпуски — бери от каждого.
   Если показатель есть в нескольких выпусках одной серии, первым бери фрагмент последнего выпуска; прошлый — только
   для сравнения или если вопрос о нём.
2. Оцени по ВЫБРАННЫМ фрагментам: можно ли ответить на все части вопроса только по ним (метод «sufficient context»).

Верни ТОЛЬКО JSON:
{{
  "selected": [3, 1, 7],               // номера фрагментов (#N), лучшие первыми
  "verdict": "sufficient" | "partial" | "insufficient",
  "missing": ["чего не хватает для полного ответа"],
  "freshness_gap": true|false,         // вопрос про события или цены после даты публикации отчётов
  "reason": "1–2 предложения"
}}
sufficient — можно ответить на все части вопроса с цифрами; partial — на часть; insufficient — нельзя.
