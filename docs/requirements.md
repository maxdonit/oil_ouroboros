# Требования к агенту «Старший аналитик нефтегазового рынка»

Исходная постановка продукта: что агент должен уметь и в каком виде его поставляют. Как закрыт каждый пункт —
[README](../README.md#требования-и-как-они-закрыты); итоги замера качества — [eval_report.md](eval_report.md).

## Цель

AI-агент в роли **«Старший аналитик нефтегазового рынка»** на основе [Ouroboros](https://github.com/razzant/ouroboros):
- отвечает на профильные вопросы отрасли;
- прогнозирует цены на нефть расчётным модулем;
- ищет гибридно — по базе отраслевых отчётов (RAG) и по открытым источникам в интернете;
- отдаёт приоритет верифицированной информации из загруженных отчётов.

## Функциональные требования

### Р1. Роль и системный промпт

Агент работает в чётко заданной роли «Старший аналитик нефтегазового рынка». Описаны:
- **экспертиза:** Upstream, Midstream, Downstream, ценообразование Brent / WTI / Urals, ОПЕК+, санкционная повестка,
  спрос и предложение;
- **стиль ответа:** структурированный, с цифрами, со ссылками на источники;
- **поведение без данных:** явно сообщать о неопределённости, не выдумывать цифры.

### Р2. База отраслевых отчётов (RAG)

- Документы разбиваются на фрагменты с метаданными: название отчёта, дата, страница.
- Векторизация — современная embedding-модель (OpenAI, BGE, E5, multilingual-e5 и т. п.).
- Хранение — векторная БД (Chroma, FAISS, Qdrant, Weaviate).
- Поиск возвращает top-k релевантных фрагментов; источник обязательно указывается в ответе.

### Р3. Интернет-поиск

Инструмент веб-поиска (Tavily, SerpAPI, DuckDuckGo, Google Custom Search или аналог) для актуальных данных: свежие
новости, текущие котировки, заявления регуляторов. Источники фильтруются: жёлтая пресса не используется как опора.

### Р4. Приоритет источников и маркировка

1. Сначала ответ ищется в базе отчётов аналитических агентств: ОПЕК, МЭА, EIA.
2. Если данных в отчётах достаточно, они — основной источник.
3. Интернет — дополнение или случай, когда нужна актуальность (новости, текущие цены).
4. В ответе явно помечено, откуда каждая информация: `[Отчёт OPEC MOMR, март 2025]` против `[Источник: Reuters, web]`.

### Р5. Расчётный модуль прогноза цен

Отдельный инструмент, который агент вызывает на запросы вида «спрогнозируй цену Brent на 3 месяца», «оцени диапазон
цен при сокращении добычи на N млн б/с»:
- загрузка исторических цен (yfinance, EIA API или подготовленный CSV);
- минимум два метода прогноза: ARIMA / SARIMA, Prophet, экспоненциальное сглаживание, регрессия по факторам спроса и
  предложения, LSTM (по желанию);
- прогноз с доверительным интервалом и краткой интерпретацией;
- агент сам решает, когда вызывать модуль.

## Технические требования

| № | Требование |
|---|---|
| Т1 | Python 3.10+ |
| Т2 | Фреймворк агента — LangChain / LangGraph |
| Т3 | LLM — любая (GPT, Claude, GigaChat, YandexGPT, локальная Llama / Qwen); в README — почему выбрана |
| Т4 | Простой UI: Streamlit, Gradio или FastAPI с минимальным фронтом |
| Т5 | Dockerfile и запуск одной командой |
| Т6 | Все ключи и параметры — через `.env`, с примером `.env.example` |
