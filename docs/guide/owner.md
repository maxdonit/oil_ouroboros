# Канал владельца: свой UI Ouroboros, Telegram, утренняя сводка

Канал владельца — вне требований и включён по умолчанию профилем `owner` в `COMPOSE_PROFILES` (сервисы
`ouroboros-ui`, `egress`, `schedules`). Без профиля (убрать `owner` из `COMPOSE_PROFILES` в `.env`) у агента один
вход — консоль.

У Ouroboros с профилем два входа:
- **консоль** (`:38620`) — для пользователей: ход аналитика с инструментами MCP (графы LangGraph) и проверкой цифр,
  память агента — копия на ход;
- **собственный UI Ouroboros** (`http://<адрес хоста>:38630`, пароль — `OUROBOROS_PASSWORD` из `.env`, по умолчанию `ouroboros`) — для владельца.
  Там Ouroboros как есть, без ограничений консоли:
  - чат со всеми встроенными инструментами: код, shell, git, браузер, файлы, память, рои субагентов;
  - задачи, логи, расходы, настройки моделей и режимов, история git;
  - Files — тело агента, как в официальном образе: `BIBLE.md`, `prompts/`, `docs/`, исходники;
  - навыки (OuroborosHub, ClawHub), виджеты, проекты, расписания, эволюция, фоновое «сознание».

Чат владельца пишет в общую память агента. Всё, чему владелец научит агента, увидят и ходы консоли, а мониторинг
покажет это новой версией агента.

## Настройки

- **Интеграция** (шлюз LLM и модели, MCP-инструменты, пароль, бюджет) задаётся `.env` и восстанавливается при каждом
  запуске.
- **Режимы, ревью, эволюция, «сознание», субагенты, усилие, лимиты раундов и воркеров, прочие модели** — выбор
  владельца в UI (полный список — `_owner_keys` в `ouroboros/settings.template.json`). Засев их не откатывает.

По умолчанию открыто то, что Ouroboros включает сам: режим `advanced`, рои субагентов до 6, изменяющие субагенты.
Выключено до решения владельца то, что тратит деньги само или меняет каждый ход пользователей:
- эволюция после задачи (`OUROBOROS_POST_TASK_EVOLUTION`) — лишний вызов основной модели после каждой задачи
  владельца и самоизменение кода (ходы консоли и сводку она не затрагивает: у них инструмент эволюции отключён);
- фоновое «сознание» — бюджет `OUROBOROS_CONSCIOUSNESS_DAILY_USD` = 0;
- LLM-проверка безопасности (`OUROBOROS_SAFETY_MODE`) — платный вызов лёгкой модели перед каждым вызовом MCP:
  замедлила бы и удорожила каждый ход консоли;
- ревью результата задачи (`OUROBOROS_TASK_REVIEW_MODE`) — платный ревьюер на основной модели;
- кампании эволюции — запускаются командой `/evolve on` в чате владельца.

Всё это включается в UI Ouroboros. Жёстких лимитов денег два: у шлюза (`GATEWAY_BUDGET_USD`) и у самого Ouroboros
(`OUROBOROS_TOTAL_BUDGET`): оба копятся за всё время, на нуле лимита Ouroboros задачи встают на паузу. Что делает
каждый ключ настроек — [справочник параметров](parameters.md#3-настройки-ouroboros).

## Выход в интернет

Ouroboros живёт в сети `agent` без выхода наружу: LLM — через шлюз, веб аналитика — через инструменты. Telegram и
навыкам владельца нужен выход, и он идёт только через `egress` (`src/oil_ouroboros/egress.py`): прокси пропускает
только HTTPS (CONNECT на порт 443) и только к хостам `EGRESS_ALLOW` (по умолчанию `api.telegram.org`; для навыков
допишите их хосты). Если у хоста нет прямого выхода (`deploy/compose/proxy.yml`), туннель идёт через прокси
организации — список разрешённых хостов действует и тогда.

## Telegram

Штатный навык `telegram`, владелец — один.
1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Впишите токен в UI Ouroboros: Settings → Secrets, `TELEGRAM_BOT_TOKEN`. Можно и в `.env`: засев положит его один
   раз.
3. Skills → `telegram`: выдайте навыку этот секрет, в настройках навыка задайте `TELEGRAM_PROXY = http://egress:3128`
   и включите навык.
4. Напишите боту в личку: первый собеседник становится владельцем — сделайте это сразу после включения.

Mini App навыка публикует UI Ouroboros наружу через Cloudflare Quick Tunnel; если он не нужен, выключите его в
настройках навыка — текстовый бот работает и без него.

## Утренняя сводка

Штатное расписание Ouroboros `oil-morning-brief` (Schedules), каждый день в 9:00 по Москве.
- **Что в ней:** котировки Brent и WTI (`price_quote`: фьючерсы Мосбиржи с временем сделки), закрытие Brent и WTI
  по EIA и изменение за неделю, 3–5 главных новостей
  рынка за сутки, выпуски OPEC MOMR / IEA OMR / EIA STEO за неделю или ближайший по графику.
- **Как собирается:** задача по расписанию со скрытым ходом. Агент зовёт `list_reports`, `price_quote`, `price_history`, `research`
  (веб за сутки), пишет сводку со ссылками и проходит `verify_answer(render=true)`: каждая цифра сверена с
  источником, ссылки заменены метками. Встроенные инструменты — как в ходе консоли плюс заметка владельцу: контекст
  ~68 тыс. токенов. На профиле openrouter сводка стоила ~$0.025 (~$0.75 в месяц; замер до двух вызовов `price_quote`),
  на GigaChat Freemium — $0, расход — в токенах журнала шлюза.
- **Как доставляется:** заметкой владельцу (`schedule_followup(notify=true)`) — в чат Ouroboros и в Telegram. Навык
  в режиме `telegram_only` пересылает разговор из Telegram и заметки владельцу, остальное остаётся в UI.
- **Откуда выпуски:** наблюдатель проверяет сайты агентств каждые `REPORTS_WATCH_HOURS` ч и сразу индексирует новый
  выпуск. opec.org закрыт проверкой от ботов: новый OPEC MOMR загружается вручную (`oilo reports --upload`).
- **Кто ведёт:** описание — [ouroboros/schedules/oil-morning-brief.json](../../ouroboros/schedules/oil-morning-brief.json).
  Сервис `schedules` создаёт расписание и обновляет его до новой версии из репозитория, пока владелец его не менял;
  дальше расписание ведёт владелец (выключить, изменить время, удалить) — засев правку не откатывает; `docker compose run --rm schedules schedules --force` вернёт версию из репозитория.

## Риски канала владельца

- Агент здесь без ограничений консоли. Веб-текст, прочитанный в чате владельца, может попасть в общую память, которую
  видят и ходы консоли.
- Пароль UI по умолчанию — `ouroboros`, его знает каждый, кто читал README, а по шаблону `.env` (`OILO_BIND=0.0.0.0`)
  UI виден в сети хоста. Впишите свой `OUROBOROS_PASSWORD` в `.env` и пересоздайте сервисы
  ([operations.md](operations.md#7-обновление)); порт 38630 в интернет не пробрасывайте — у агента там shell.
- В продуктиве: включить проверку безопасности Ouroboros (`OUROBOROS_SAFETY_MODE`), не давать каналу владельца
  писать в регламент, сразу занять владельца Telegram-бота и выключить Mini App, если он не нужен.
