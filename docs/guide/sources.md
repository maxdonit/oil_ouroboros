# Источники: что подключено и как добавить новый

У агента четыре вида источников. Что подключено сейчас, насколько это свежо и достоверно — вкладка консоли
«Источники».

| Источник | Достоверность | Свежесть | Где задаётся |
|---|---|---|---|
| Отчёты агентств: OPEC MOMR, IEA OMR (публичная часть), EIA STEO | уровень 0 — первичный источник, приоритетный | последние выпуски каждой серии; новые скачивает наблюдатель | `data/reports/catalog.yaml`, правила скачивания — `config/current/reports.yaml` |
| Веб-поиск: Tavily → Brave → DuckDuckGo | уровень домена 0–3 или deny; цифры подтверждают только уровни 0–2 | свежие новости и котировки | доверие к доменам — `config/current/source_tiers.yaml`, когда идти в веб — `config/current/web.yaml` |
| Цены EIA: Brent, WTI — для прогноза, сценария и истории; спот газа Henry Hub — рядом с котировкой | уровень 0 — официальная статистика | обновление при старте и каждые 6 ч; EIA выкладывает раз в неделю — отставание до недели | `src/oil_ouroboros/forecast/data.py` |
| Котировки Мосбиржи (`price_quote(benchmark)`): фьючерс ближайшего месяца — Brent, WTI, газ Henry Hub, газ TTF; ISS без ключа | уровень 0 — данные биржи | по запросу агента, задержка 15 мин, кэш 5 мин; при сбое — сохранённая с пометкой | `src/oil_ouroboros/forecast/quotes.py`, сорта и параметры — `forecast.quote` в `config/current/forecast.yaml` |

Правило приоритета — код, а не модель: `research` всегда начинает с отчётов, в веб идёт, если вопрос про свежие
события, отчётов не хватает или между их датой и вопросом разрыв (`config/current/web.yaml`). Домены из deny не
попадают в контекст; уровень 3 (неизвестный домен, государственные СМИ, ленты пресс-релизов) можно упомянуть как фон,
но цифры на нём не подтверждаются.

Фьючерс и спот — разные цены: котировка Мосбиржи (контракты рассчитываются по фьючерсам NYMEX и ICE) — это «цена»
из новостей, спот EIA — физический товар (Dated Brent, WTI Cushing, Henry Hub), со своей датой; у TTF открытого
дневного спота нет. Новый сорт Мосбиржи добавляется строкой в `forecast.quote.instruments`: код актива ISS, названия,
единица и, если есть, ряд спота EIA. Условия ISS разрешают бесплатно брать
задержанные данные; распространение в коммерческом продукте — по договору с биржей.

## Как добавить источник

Каталог отчётов, правила и `data/reports` лежат в образах, поэтому после правки нужна пересборка (на стенде её делает
`scripts/deploy.py up`). Код при этом не меняется.

1. **Новый выпуск серии, которая уже подключена** — ничего не нужно: наблюдатель скачает его сам (при старте и каждые
   `REPORTS_WATCH_HOURS` ч) и добавит в индекс. Проверить сейчас:
   `docker compose exec tools oilo reports --check`. Если сайт закрыт проверкой от ботов (opec.org, Cloudflare), файл
   загружают вручную — серия и месяц определяются по обложке, выпуск сразу индексируется:

   ```bash
   docker compose cp OPEC_MOMR_November_2026.pdf tools:/tmp/momr.pdf
   docker compose exec tools oilo reports --upload /tmp/momr.pdf
   ```

2. **Новый отчёт или новое агентство** — файл (PDF или HTML) в `data/reports/`, запись в
   `data/reports/catalog.yaml`: `file`, `org`, `report`, `title`, `edition` (ГГГГ-ММ), `published`, `url`, `license`.
   Затем `docker compose up -d --build tools encoder` и `docker compose exec tools oilo ingest`. Агентство само
   попадает в фильтр поиска и в промпт планировщика, агент видит отчёт в `list_reports`.

3. **Чтобы новые выпуски серии скачивались сами** — правило серии в `config/current/reports.yaml`: ссылки с
   подстановками (`{yyyy}`, `{mm}`, `{month}`, `{mon}` …), график `schedule` или `earliest_day`, сколько выпусков
   держать (`lookback`), слова обложки `detect` для ручной загрузки. Затем `docker compose up -d --build tools`.

4. **Доверие к веб-домену** — домен в `tier0` / `tier1` / `tier2` или `deny` в `config/current/source_tiers.yaml` и
   новая `version` (она пишется в журнал каждого решения фильтра); затем `docker compose up -d --build tools`.
   Домен агентства — уровень 0. Проверить, какой уровень получит адрес, — поле «Проверить домен» на вкладке
   «Источники».

5. **Провайдер веб-поиска** — `TAVILY_API_KEY` или `BRAVE_API_KEY` в `.env` (выбор — `WEB_PROVIDER`, по умолчанию
   `auto`), затем `docker compose up -d tools`; без ключей — DuckDuckGo.

Источник другого типа (API, база данных, новый ряд цен) потребует кода: свой граф в `src/oil_ouroboros/graphs/` и
инструмент в `src/oil_ouroboros/mcp/server.py`, по образцу `calc.py`.

## Как устроено внутри

- **Выпуски** (`src/oil_ouroboros/reports/`): `editions.py` — какие выпуски есть (курируемые в git и пришедшие
  позже); `watch.py` — наблюдатель: график → проверка сайта → скачивание → проверка обложки; `queue.py` — очередь
  индексации (во время замера eval выпуск ждёт); `journal.py` — журнал наблюдателя.
- **Индекс** (`src/oil_ouroboros/rag/`): разбор (Docling) → фрагменты с отчётом, выпуском, датой и страницей →
  векторы BGE-M3 → Qdrant. Индексирует кодировщик (`encoder`).
- **Веб** (`src/oil_ouroboros/web/`): `search.py` — провайдеры, кэш, два прохода (сначала домены уровней 0–1);
  `credibility.py` — уровень домена: курируемые списки, затем экспертный рейтинг качества доменов (Lin et al.,
  PNAS Nexus 2023; `data/source_quality/domain_pc1.csv`).
- Права на данные — [NOTICE.md](../../NOTICE.md).
