# Отчёт: решения, качество, ограничения, что улучшить

## Принятые решения и почему

- **Агент — Ouroboros, функции — LangGraph по MCP** ([ADR-0001](adr/0001-ouroboros-as-agent.md)). Приоритет
  источников, проверка цифр и финал хода живут в коде инструментов, а не в промпте: их не обойти «авторитетным видом»
  страницы или уверенностью модели.
- **Ход — задача API, а не WebSocket-чат.** Только так у хода есть свой id, лишние встроенные инструменты
  отключаются, а запись в память изолирована.
- **Роль — в памяти агента.** Регламент всегда в контексте. Агент может улучшать его штатно, с журналом изменений;
  засев правку агента не затирает.
- **Модель пишет id, код — метки.** Метки, список источников и строку проверки рендерит код по журналу доказательств,
  поэтому модель не может их подделать. Что увидит пользователь консоли, решает финал хода в сервисе инструментов.
- **Ссылки — только своего хода.** MCP-вызов не несёт id хода, поэтому агент передаёт в `verify_answer` номера
  пакетов своего хода. Id из соседней задачи Ouroboros или из памяти проверка считает чужим ещё до завершения ответа.
- **Без GPU.** Cross-encoder на CPU тратит 24–130 с на вопрос, поэтому фрагменты отбирает LLM инструмента: это один
  дешёвый вызов, и он же оценивает достаточность отчётов.
- **Отдельный LLM-шлюз с кэшем промпта.** Агент без выхода в интернет доходит до модели только через шлюз; ключ
  провайдера знает только он. На маршруте `openai-compatible::` Ouroboros снимает маркеры кэша Anthropic, шлюз
  возвращает их на место: на профиле openrouter (модели `anthropic/*`) раунд стоит ~$0.001–0.002 вместо ~$0.007. На
  GigaChat Freemium вызовы бесплатны, расход — в токенах.
- **Ядро и профили разделены.** Требованиям нужно ядро из семи сервисов; UI владельца, Telegram и утренняя сводка —
  профиль `owner`, прокси GigaChat — профиль `gigachat`. Шаблон `.env.example` включает оба (`COMPOSE_PROFILES`).

## Качество

Dev-набор — 42 вопроса с эталонными цифрами и ожиданиями: маршрут, инструменты, типы ссылок, отказ, честность,
уточнение в диалоге, вопросы на английском. Каждый кейс — настоящий ход агента через Ouroboros, проверки
детерминированные, без LLM-судьи.

```bash
docker compose exec console oilo eval --only R01 F01 O01                         # выборочно
docker compose exec console oilo eval --label baseline --report var/eval.md      # весь набор: OpenRouter ~$0.35, ~22 мин; GigaChat — ~4 млн токенов Ultra, ~11 мин
docker compose exec console oilo compare <id базы> <id кандидата>                # McNemar по кейсам
docker compose exec tools oilo eval-retrieval --label baseline                   # поиск и отбор по слоям, без агента
```

**Профиль по умолчанию (`gigachat`)** — полный набор 2026-10-26 на чистой установке: агент и инструменты —

Где агент ошибался (7 кейсов):
- **Лишний отказ (W02, A01).** Вопрос о новостях судоходства через Ормузский пролив агент счёл вне компетенции; на
  вопрос об инвестициях отказал целиком, а нужен отказ от совета с рыночным контекстом.
- **Нужный факт не найден (R05, R06, R09, R16).** Изменение мировых запасов (IEA OMR, таблица 3a EIA STEO) и пересмотр
  прогноза спроса в OPEC MOMR не попали в отбор фрагментов: агент ответил по найденному, не выдумывая цифр.
- **Лишний веб (R17).** Оценщик достаточности счёл отчёты неполными, хотя ответ в них был.

**Профиль `openrouter`** (агент `claude-haiku-5.5`, инструменты `gpt-6-luna`) — полный набор 2026-10-26, та же чистая
установка, версия агента `a3357e025947`: 38/42 = 90% (95% ДИ 78–96%), цифры показанного ответа подтверждены на 100%,
ответ = проверенный текст — 97%, p50 / p95 — 61 с / 98 с, ~$0.008 на ответ (весь прогон $0.33, 22 мин — по журналу
LLM-шлюза). Ошибки: лишний веб (R06, R10, R14) и инвестсовет без `research` первым шагом (A01). Отчёт по кейсам —
[eval_report.md](eval_report.md), демо-диалоги той же версии — [demo_dialogs.md](demo_dialogs.md).

**Мониторинг.** Вкладки консоли «Ходы», «Мониторинг» и «Качество» показывают онлайн-проверки каждого хода: сначала
отчёты, проверка пройдена, ответ = проверенный текст, ссылки только этого хода, метки, язык. Версия агента — это
отпечаток: Ouroboros, память, модели, шаблон хода, инструменты MCP, каталог `config/`, база отчётов; по нему видно,
что изменилось и кем — засевом из репозитория или самим агентом.

## Ограничения

- **Ядро Ouroboros в каждом раунде.** SYSTEM.md + BIBLE.md весят ~22 тыс. токенов, с картами архитектуры ~29 тыс.;
  на профиле openrouter (модели `anthropic/*`) цену держит кэш промпта, на GigaChat Freemium это расход квоты токенов.
- **Агент одного владельца.** История разговора идёт в тексте задачи, запись памяти — в копию на задачу. Читает ход
  общую память, поэтому в его контексте и разговор владельца в UI Ouroboros (комната Main): штатного рычага у задачи
  API нет.
- **Новые выпуски OPEC MOMR** загружаются вручную (Cloudflare). У IEA OMR — только публичная часть.
- **Прогноз.** Статистика не знает событий после даты данных; Urals = Brent − сценарный дисконт (открытого ряда
  Urals нет); метод в `auto` выбирается по тому же бэктесту, по которому считаются скилл и покрытие, поэтому оценки
  слегка оптимистичны.
- **Проверка цифр — код, а не смысл.** Она находит число той же единицы и направления в процитированном источнике
  (или воспроизводит арифметику пометки «(расчёт)»), но не понимает, о том ли показателе фраза. Правильность фактов
  мерят кейсы eval с эталонными цифрами.
- **Eval.** Один dev-набор на 42 кейса и 1 повтор, регламент настраивался на нём же. Отложенного набора нет, и
  McNemar на таком объёме различает только крупные изменения.
- **Веб.** При исчерпанном лимите Tavily поиск переходит на DuckDuckGo: качество ниже, ответ с вебом — до 2,5 мин.

## Что улучшить при большем времени

- **Поиск по отчётам.** Табличные фрагменты с заголовками строк и столбцов — отдельным видом поиска; для EIA STEO —
  ряды через EIA API вместо разбора таблиц PDF.
- **Самоулучшение.** Задача по расписанию разбирает провалы eval и предлагает правку регламента или каталога; правка
  проходит экспериментальный слот, eval и решение человека.
- **Методика eval.** Отложенный тестовый набор, pass^k по 3 повторам, цели фиксировать до замера.
- **Реранкер на GPU** (`RERANKER=bge-reranker-v2-m3`) и полный текст цитируемых веб-страниц.
